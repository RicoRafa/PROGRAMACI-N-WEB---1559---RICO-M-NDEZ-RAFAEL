Resumen HTML: principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en la clase de programación web 1, en el módulo html

Conceptos principales html

HTML

Hyper Text Markup Language: Es un lenguaje de marcas que se utiliza para estructurar sitios web

Elemento HTML

Un elemento html es la unidad básica de estructura y contenido en una página web, y esta compuesta de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <Head>

Es una etiqueta que se utiliza para comunicarse con el navegador a través de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web

Contenedores semanticos

<head> Etiqueta utilizada para el contenido introductorio de una página web, puede contener logo, menú de navegación, nombre de la empresa, etc.
<nav> Etiqueta utilizada para el menu de navegación principal, suele contener enlaces a otras páginas relacionadas, o navegar por la página principal, no debe de haber más en la página (solo 1 nav)
<main> Etiqueta única cuyo propósito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido principal de nuestra página
<section> Etiqueta que poco a poco se intenta que sustituya a <div>, su uso es para dividir a una página web en secciones y agrupar contenido relacionado
<article> Etiqueta que se utiliza para agrupar contenido autonomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido
<footer> Etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria
<aside> Etiqueta que representa una sección de la página web cuyo contenido no está directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros articulos relacionados, etc.
